# HardLister

A lightweight, high-precision standalone iOS and Android application built using Expo and TypeScript. HardLister is engineered for rapid documentation, physical serial authentication, and conditional state testing of hard goods, tools, appliances, electronics, and production-grade camera optics.

## Features
* **Multi-Category Spec Routing:** Swaps structural input layouts dynamically based on category selection to keep form inputs light and fast.
* **Component Wear Logging:** Standardized tracking parameters for shutter actuation counts, physical battery cycle health percentages, operating voltage steps, and optical clarity markers.
* **Zero-Bloat Asset Streamer:** Uses native device file streaming boundaries to pipe binary multipart payloads straight to cloud destination folders without Base64 expansion.

## Architecture Parameters
* **Frontend Core:** Expo SDK Managed Workflow & React Hooks
* **Local Data Layer:** AsyncStorage Offline Sync Queue
* **Target Backend:** Google Sheets Column Matrices & Google Drive Target Directories
